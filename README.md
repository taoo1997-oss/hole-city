# Хоул

Офлайн-игра в духе hole.io: управляешь дырой в городе, глотаешь людей, машины и дома, дыра растёт.

- 100 уровней. На каждом нужно проглотить заданное число предметов за время и найти обязательные (жёлтые маркеры).
- Каждый 5-й уровень сложный, каждый 10-й очень сложный.
- Управление: тянуть пальцем или мышкой в любом месте экрана, на клавиатуре WASD или стрелки. Пауза: Esc.
- Без рекламы, без онлайна. Прогресс хранится в браузере.

Играть: https://taoo1997-oss.github.io/hole-city/
